# Project rules for the AI assistant

- Read docs/PRD.md before changing anything. It is the source of truth.
- Do not invent data, numbers, quotes or results. Leave placeholders for real data.
- Before editing, read the relevant code and summarize your plan in 5 lines.
- Make the smallest change that satisfies the task. Do not refactor unrelated code.
- Run the code or tests after changes. Report the actual output, not what you expect.
- If something fails, show the error and the fix. Do not say it works without running it.
- Ask me when a requirement is ambiguous instead of guessing.
- Commit messages: plain, lowercase, say what changed.
